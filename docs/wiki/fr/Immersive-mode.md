# Mode immersif

[English](../Immersive-mode.md) · **Français** · [Deutsch](../de/Immersive-mode.md)

Le donjon est reconstruit en vraie 3D autour de toi, à taille réelle, à partir de tes propres fichiers du jeu : murs, décorations, portes, sols et plafonds, monstres et objets (dessinés par le jeu lui-même et toujours tournés vers toi). Il n'y a qu'une seule vue : ni réalité mixte ni PC 486 dans ce mode.

- **Marcher** : le joystick gauche s'oriente par rapport à ton regard. Devant, c'est là où tu regardes ; de côté, c'est un pas de côté. Quand tu ne bouges pas, le groupe se tourne doucement vers ton regard (pas quand tu vises une fenêtre), pour que le mur « devant » et les attaques soient ceux que tu vois.
- **Tourner** : le joystick droit tourne avec un très court fondu, pour rester confortable.
- **Cliquer dans le donjon** : vise un mur autour du groupe (boutons de porte, leviers, serrures, buissons, nids, trous dans les arbres) ou le sol devant toi (objets) et appuie sur la gâchette.
- **Boutiques et autres régions** : leurs portes et leurs images sont des murs ; avance dedans et l'écran du jeu montre la boutique, ou la nouvelle région apparaît. Dans les boutiques et les conversations, la ligne de messages avec les choix apparaît dans sa propre fenêtre, juste sous le cadre de l'écran du jeu ; quand le jeu ouvre sa grande boîte de texte (conversations et remarques, avec le portrait de celui qui parle, quand le texte du jeu est activé), toute la boîte y apparaît. On y clique ses choix.
- **Objets** : prends-en un dans l'inventaire et vise devant toi dans le donjon pour le lancer ou le poser ; l'objet reste au bout de ton pointeur.
- **L'écran du jeu** apparaît tout seul pour les boutiques, les conversations, les scènes, la carte, les menus et les fiches de personnage, et se cache de nouveau quand ils finissent.
- **Lumière** : les endroits sombres restent sombres tant que tu n'as pas allumé la lanterne, selon la luminosité du jeu lui-même.
- **Sorts** : leurs effets, tels que le jeu les dessine sur sa vue, apparaissent dans le donjon devant le groupe pendant le sort.

Les portes montent dans leur cadre par étapes, comme dans le jeu. Les objets lancés et les projectiles traversent le donjon à la hauteur que le jeu leur donne.

Pour passer à la vue classique, dans « Réglages VR » (menu du jeu, disquette sur le poignet gauche) : « Mode VR », Classique ou Réalité mixte.
