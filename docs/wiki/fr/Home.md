# Lands of Lore VR

[English](../Home.md) · **Français** · [Deutsch](../de/Home.md)

*Lands of Lore: The Throne of Chaos* (Westwood, 1993) en réalité virtuelle sur **Meta Quest 3**, en autonome, sans PC.
Le jeu original tourne sur [ScummVM](https://www.scummvm.org) ; l'application ajoute deux façons de jouer :

- **Mode immersif** : tu marches dans le donjon, reconstruit en 3D autour de toi à partir de tes propres fichiers du jeu. L'écran du jeu n'apparaît qu'au besoin (boutiques, conversations, carte, menus).
- **Vue classique** : le jeu original sur un grand écran, dans une bibliothèque médiévale, dans ta propre pièce (réalité mixte) ou sur un vieux PC 486, avec une interface déplaçable.

Au premier lancement, une fenêtre te demande laquelle tu veux ; tu peux changer quand tu veux dans « Réglages VR », dans le menu du jeu (la disquette sur ton poignet gauche).

**Les fichiers du jeu ne sont pas fournis** : il te faut ta propre copie du jeu (version CD ou GOG).
